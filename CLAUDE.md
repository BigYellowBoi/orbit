# Orbit – working notes

Training log for Louis (BigYellowBoi): a rotating split (Push 1, Pull, Push 2, Legs; optional Upper/Lower/Push/Pull/Legs), WHOOP and MacroFactor imports, maintenance goal by default, with an optional Overload mode for the Aim (Plan → Targets; `S().goal` 'hold' | 'grow', `progRate`, `growFrom`). Aim logic lives in engine.js; check changes with a follow-the-Aim simulation (maintenance must stay flat, overload must climb at each rate). Single-file vanilla JS app, dark theme, Geist fonts. No framework, no bundler.

User preferences: short answers, never use em dashes (in replies or UI copy). Keep the soft neon-purple glow on the header logo (he likes it). iOS draws a blurred band over the top of home-screen apps reaching ~14pt below the status bar; the header row sits 14pt lower in standalone mode (`--hdrdrop`), the only position he found sharp (v1.3 and v1.5 tests, tinted headers didn't help).

Any feature change goes into `src/`, then `tools/build.sh` rebuilds both. Ship to both targets unless told otherwise. Bump `VERSION` (1.1 → 1.2, …) on every ship and tell Louis the new number: it shows at the bottom of the Data screen, and `version.json` makes the home-screen app show an update prompt above the tab bar on any screen when it's behind (checked on open, on return to the app and every 15 min; Later hides it until the next open). The sandbox clock is unreliable, so never use build times.

## Sync helper (worker/)
`worker/orbit-sync.js` is a Cloudflare Worker (free plan) Louis runs himself: WHOOP API v2 (OAuth, webhooks, cron every 10 min, history backfill) and Apple Health numbers from an iPhone Shortcut (`POST /health`), both written into `orbit/dy/YYYY-MM.json` in `orbit-data` via the GitHub contents API. Pages app only; the artifact isn't touched. Setup is in `worker/README.md`; secrets live in Cloudflare only. Free plan: 50 outside requests per run (worker budgets 45), so keep request counts in mind. WHOOP has no webhook for cycles (day strain, steps), so between 3-hourly full syncs the cron refreshes today's cycle every 30 min (`pollToday`, 1 WHOOP call, GitHub only when changed). Test with `node test/worker.mjs`. Louis pastes the code into Cloudflare by hand, so tell him when `orbit-sync.js` changes.
The Data screen's **Automatic sync** card (Pages only, `Helper` in gh.js) reads `<helper>/status.json` (CORS *, no secrets: WHOOP connected/checkedAt/error/history, Apple Health last POST from KV `healthAt`); the address is `S().helper`, entered once on that card.
Day fields from it: WHOOP keys as the CSV import plus `stp` (WHOOP steps); Health: `stpi` (iPhone steps), `hp` (headphone dB, time-weighted energy average), `hpm` (headphone minutes), `kcal/p/c/f/wt`. Orbit derives trend weight and expenditure (`derived()` in engine.js) where MacroFactor's export has none. The GitHub merge combines day fields from the repo and a dirty local day (local wins per field).

## Layout
- `src/head.html` CSS tokens and styles; `src/body.html` shell (fixed header with the ring, 5 tabs: Today, History, Strength, Body, Plan; toast); `src/gh-head.html` the Pages-only document head (meta, icons; in standalone mode the header row sits 14pt lower via `--hdrdrop` to clear iOS's top blur band). The page scrolls normally by default; a pinned app-shell layout (body fixed, 100vh/100% heights) was tried and cropped the bottom on Louis's iPhone 13 Pro Max (WebKit bug 254868), so don't reintroduce that. The home-screen app uses the **Scroll box** layout (`html.sbox`, set in gh-head.html; opt-in from v1.9, the only Pages layout since v1.12, switch removed): `#scroll` is position: fixed with all four edges anchored (no vh), and only it scrolls. Reason: iOS swallows a tap that stops page momentum (no touch/pointer/click event), so with the page scrolling a tab tap mid-fling only stops the scroll; outside the scrolling box it arrives. `resetScroll()` in sbox swaps in a fresh `#scroll` to kill momentum (no overflow toggling). v1.9 overrode body's min-height: 100vh in sbox and left a ~47pt black strip under the tab bar on the phone; v1.10 keeps it. v1.11: on short pages #scroll had nothing to scroll, so swipes rubber-banded the page and tab taps were swallowed ~0.5-1 s; `.wrap` now has min-height 100% + 1px in sbox and html/body get overscroll-behavior: none. Confirmed working on Louis's phone. Status-bar tap-to-top doesn't apply inside the box. Tabs and the gear navigate on pointerdown; use the scroll helpers in boot.js (`scrollToY`, `resetScroll`), never `window.scroll*` directly. Playwright WebKit can't be downloaded here; iOS is tested with Chromium iPhone emulation, and real-device layout questions need Louis's screenshots.
- JS, concatenated in this order: `core.js` (helpers, exercise library, presets, STATE, ui), `engine.js` (rotation, e1RM/PRs, maintenance check, suggested load and reps, HRV band, cardio auto-log from WHOOP, which overrides hand entries), `imports.js` (WHOOP zip/CSV via JSZip 3.10.1, MacroFactor xlsx via SheetJS 0.18.5, both lazy-loaded from cdnjs), `charts.js` (hand-built SVG), `explorer.js` (Trends metric explorer), `notes.js`, `views.js` (Today, which holds today's log once started; Log, a past day opened from History; History; Strength; Body; Plan; Data), `boot.js` (persistence, render, actions, boot). `gh.js` is appended for Pages only.
- `tools/build.sh` builds; `tools/icons.js` renders `tools/icon.html` to the PNG icons.
- `test/` Playwright scripts: `gh.js` (GitHub sync against a mocked API: two devices, conflicts, offline, delete, restore), `sync.js` (artifact cloud sync with a mocked `window.claude`), `notes.js`. Run with `PLAYWRIGHT=/path/to/playwright node test/gh.js` after building.

## Data
- localStorage key `rotation-logbook-v1` holds `{settings, w, d}` (kept for continuity).
- `STATE.w[date]` workouts `{s, ex:[{id, sets:[{w,r,done}], note}], cardio, rest, note}`; `STATE.d[date]` WHOOP + MacroFactor day fields.
- Artifact cloud: `data/users/<uid>/settings` and month docs `.../log/{wk|dy}/YYYY-MM`.
- GitHub: `orbit/settings.json`, `orbit/{wk|dy}/YYYY-MM.json` in `orbit-data`. Token lives only in each device's localStorage (`orbit-gh-cfg`); never ask for it, log it or commit it. Sync = read head, fetch changed blobs, merge (dates edited locally and unpushed win), one commit via the Git Data API, retry on non-fast-forward.
